Where does your music live?

The Parson server keeps your library, streams it bit-perfect and drives every speaker in the house. Run it on this computer, or use this app as a remote for a server on your network.

Run the server on this computer

  • Your library and its database stay on this computer
  • Plays to this computer’s DACs and every network zone
  • Runs in the background, so phones and other computers keep playing after you close this window

Connect to a server on my network

  • Use a Parson server on a NAS, a headless box or another computer
  • This app becomes a remote and never starts a server
  • Sign in once per server; Parson remembers each one

Servers on your network

Parson finds servers automatically with Bonjour/mDNS on port 5353. Run Parson headless on Linux, a NAS or Docker

Reconnecting…

Parson will pick up where you left off as soon as the server is back. Check that it is switched on and connected to the same network.
