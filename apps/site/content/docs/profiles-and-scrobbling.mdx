Parson is built to be shared. Everyone who listens gets a **profile** with their own listening history, likes, ratings, Radio taste, recommendations and scrobbling.

## Profiles

A profile is either:

- **An account**, which signs in with a username and password, or
- **A managed profile**, added by someone in the household (Settings → Profiles → Add profile). It has no password: you enter it by switching from a device that is already signed in.

Switch from the profile button at the top right of the app (or Settings → Profiles on the phone app). Switching changes only that device. The music keeps playing, and from then on plays, likes and Radio feedback count for the new profile.

What switching asks for:

| Profile                          | Switching asks for           |
| -------------------------------- | ---------------------------- |
| Profile or account without a PIN | Nothing, it is instant       |
| Any profile with a PIN           | Its PIN (4 to 8 digits)      |
| Administrator without a PIN      | The administrator's password |
| Account hidden from the switcher | Its password                 |

Wrong PINs are rate limited. Administrators who want one-tap switching to their own profile can set a PIN. Whoever added a managed profile, and administrators, can edit or remove it; removing deletes its history after a safety backup.

## Scrobbling

Each profile connects its own accounts under Settings → Scrobbling, so everyone's scrobbles stay their own.

- **Last.fm** uses Last.fm's web sign-in. Last.fm requires an API account per application, so an administrator creates one at [last.fm/api/account/create](https://www.last.fm/api/account/create) and pastes the API key and shared secret into Settings → Scrobbling. They are stored encrypted. Servers can also set `PARSON_LASTFM_API_KEY` and `PARSON_LASTFM_API_SECRET`.
- **ListenBrainz** uses your user token from [listenbrainz.org/settings](https://listenbrainz.org/settings/). Self-hosted ListenBrainz servers work by setting `PARSON_LISTENBRAINZ_API_URL`.

Parson follows Last.fm's rules for every service:

- Tracks of 30 seconds or less are never scrobbled.
- A track counts once you have heard half of it or four minutes, whichever comes first.
- The scrobble is stamped with the time you started listening.
- "Now playing" is sent when a track starts (you can turn it off).
- Tracks Radio picked are sent as "not chosen by you", and can be left out entirely.

The server keeps scrobbles in a queue. When a service or the server is offline, listens wait and are sent later with their original times, retrying with growing gaps up to six hours. Last.fm does not accept scrobbles older than 14 days; ListenBrainz accepts any age. If a service revokes the connection, the queue pauses until you connect again.

### Importing history

On a connected service, **Import history** reads your past listens, matches them to songs in your library and adds the matches to the profile's history with their original dates. Imported listens shape Radio and recommendations straight away. Listens already in Parson are not added twice, and songs you do not have are skipped.

### Trying it without accounts

Start the server with `PARSON_SCROBBLING_SANDBOX=1` to run the whole flow against recorded Last.fm and ListenBrainz replies, without network access or accounts.
